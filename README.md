# Accessible Form UI

This project is an **Accessible Form UI** component created using **HTML and CSS**, based on the **Roadmap.sh Accessible Form UI** project requirements.

🔗 **Project URLs**  
- **Live Project:** https://accessible-form-ui-psi.vercel.app/   
- **Roadmap Project Reference:** https://roadmap.sh/projects/accessible-form-ui  

---

## 📌 Description

A clean, modern, and **fully accessible form user interface** designed with usability and inclusivity in mind.  
This project follows accessibility best practices such as proper labels, semantic HTML, focus states, and keyboard-friendly interactions—making it suitable for real-world applications.

---

## 🧩 Features

- Accessible and semantic HTML structure  
- Proper label and input associations  
- Keyboard-friendly form navigation  
- Clear focus and hover states  
- Clean and minimal UI design  
- Responsive layout  
- Beginner-friendly project  
- Built using pure HTML & CSS  

---

## 📂 Files Included

- `index.html` — Form structure and accessibility markup  
- `style.css` — Styling, layout, and focus states  
- `README.md` — Project documentation  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3

This project was built to practice:
